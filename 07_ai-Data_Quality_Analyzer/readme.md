## AI Data Quality Analyzer

Hands-on LangChain + OpenAI project that analyzes CSV datasets and generates an AI-powered data quality report.

🛠️ Tech Stack
🐍 Python
🐼 Pandas
🔗 LangChain
🤖 OpenAI LLM
🧩 Pydantic
📄 CSV

---
🔍 Features
Detect missing/NULL values
Identify invalid values and formats
Find potential duplicates and inconsistencies
Generate a data quality score
Return structured output using Pydantic

---
🏗️ Flow
CSV → Pandas → LangChain → OpenAI LLM → Pydantic → Data Quality Report
